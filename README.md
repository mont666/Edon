# Дизель Резерв — сайт продажу генераторів EDON

Статичний сайт (HTML/CSS/JS без фреймворку) для продажу промислових дизельних генераторів EDON
30–200 кВт: головна з вибором моделі та калькулятором потужності, 7 сторінок товарів, сторінки для
покупців, Schema.org, sitemap і фід Google Merchant.

```
data/products.json   каталог: ціни, характеристики, тексти моделей
data/site.json       дані бізнесу: телефон, пошта, адреса, реквізити, домен, форма, Google Ads
tools/build.mjs      генерує ВСІ сторінки сайту з даних у папку site/
site/assets/app.css  дизайн-система (правила — у DESIGN.md)
site/assets/app.js   меню, вибір моделі, калькулятор, форма, конверсії Google Ads
site/                готовий сайт — саме цю папку викладають на хостинг
```

Після будь-якої зміни в `data/` або `tools/build.mjs` запустіть:

```bash
node tools/build.mjs
```

Скрипт наприкінці перелічує, яких даних ще бракує.

## Заявки з форми: FormSubmit → kosa.shop2023@gmail.com

Форма замовлення надсилає заявки через безкоштовний сервіс [FormSubmit](https://formsubmit.co)
(`formEndpoint` у `data/site.json`). У листі — ім’я, телефон, модель з ціною, населений пункт, спосіб
оплати й коментар; тема листа: «Заявка: EDON 100 кВт, відкрита рама — Ім’я, телефон».

**Активація (один раз, після публікації сайту):**

1. Відкрийте свій сайт і надішліть через форму тестову заявку.
2. На kosa.shop2023@gmail.com прийде лист від FormSubmit — натисніть **Activate Form**
   (якщо листа немає, перевірте «Спам» і «Промоакції»).
3. Готово: далі кожна заявка приходить листом. Заявки, надіслані до активації, FormSubmit зберігає
   й доставляє після неї (до 30 днів).

FormSubmit працює лише зі сторінок, відкритих на сайті (не з файлу на комп’ютері). Захист від спаму:
приховане поле-пастка для ботів. Після активації FormSubmit надсилає «випадковий рядок» — його можна
вписати у `formEndpoint` замість адреси пошти (`https://formsubmit.co/ajax/<рядок>`), щоб пошта не
була видна в коді сторінки.

## 2. Розміщення

Будь-який статичний хостинг з HTTPS. Найпростіше — **Cloudflare Pages** або **Netlify**:
папка публікації `site`, команда збірки `node tools/build.mjs` (або збирайте локально).
`site/_headers` додає заголовки безпеки й кешування, `site/404.html` — сторінка помилки.

## 3. Чек-лист Google Ads

Що вже зроблено на сайті:

- Справжні ціни в гривнях, наявність, умови доставки, оплати, гарантії й повернення на окремих сторінках.
- Телефон, месенджери, пошта й адреса магазину — у шапці, підвалі та на сторінці «Контакти й реквізити»; реквізити продавця з’являться там само, щойно їх впишете.
- Політика конфіденційності, публічна оферта; згода під кожною формою.
- Жодних неперевірюваних тверджень («найнижча ціна в Україні», лічильники, вигадані відгуки, таймери).
- Чітко сказано, що ми дилер, а не виробник EDON.
- Унікальні тексти (не скопійовані з інших магазинів).
- Швидкість: головна ~380 КБ на десктопі, ~270 КБ на телефоні; адаптив від 320 px; доступність перевірена.
- `robots.txt` дозволяє `AdsBot-Google`; немає редиректів, клоакінгу, спливних вікон.
- Schema.org: Store, Product з Offer, доставкою й політикою повернення, FAQPage, BreadcrumbList.
- `merchant-feed.xml` для Google Merchant Center (з’являється після заповнення `domain`).

Що зробити вам:

1. Вписати `domain`, перезібрати сайт, підключити домен з HTTPS і активувати форму FormSubmit (див. вище).
2. Пройти верифікацію рекламодавця в Google Ads — дані ФОП мають збігатися з тими, що на сайті.
3. Додати сайт у Google Search Console та надіслати `sitemap.xml`.
4. У Merchant Center додати фід `https://ваш-домен/merchant-feed.xml`, доставку 0 ₴ по Україні
   і політику повернення (`/harantiia-ta-povernennia/`).
5. В оголошеннях використовувати ті самі факти, що на сайті: ціни, «доставка 0 ₴», «запуск і навчання
   на місці», «гарантія 12 місяців», «оплата на рахунок без ПДВ або готівкою».
