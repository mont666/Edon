# Резерв 400 — сайт продажу генераторів EDON

Статичний сайт (HTML/CSS/JS без фреймворку) для продажу промислових дизельних генераторів EDON
30–200 кВт: головна, 7 сторінок товарів, сторінки для покупців, Schema.org, sitemap, фід Google Merchant.

```
data/products.json   каталог: ціни, характеристики, тексти моделей
data/site.json       дані бізнесу: телефон, адреса, юрособа, домен, форма, Google Ads
tools/build.mjs      збирає сайт із даних у папку site/
site/                готовий сайт — саме цю папку викладають на хостинг
```

Після будь-якої зміни в `data/` запустіть:

```bash
node tools/build.mjs
```

Скрипт наприкінці перелічує, яких даних бракує для Google Ads.

## 1. Заповніть `data/site.json` (обов’язково перед рекламою)

| Поле | Що вписати | Навіщо |
|---|---|---|
| `domain` | `https://ваш-домен.com.ua` | canonical, sitemap.xml, фід Merchant Center |
| `phone`, `phoneDisplay` | `+380XXXXXXXXX`, `0XX XXX XX XX` | Google вимагає реальні контакти; кнопка дзвінка |
| `email` | пошта для клієнтів | контакти, політика конфіденційності |
| `city`, `street`, `hours` | місто, вулиця, графік | сторінка контактів і розмітка Store |
| `legalName`, `legalCode`, `legalAddress` | ФОП/ТОВ, ЄДРПОУ/РНОКПП, юр. адреса | оферта й повернення (закон + політика Google щодо прозорості) |
| `formEndpoint` | адреса сервісу форм, напр. `https://formspree.io/f/xxxx` | **без неї заявки з сайту не надходять** (зараз стоїть заглушка `mailto:`) |
| `googleAdsId` | `AW-XXXXXXXXX` | тег Google Ads |
| `googleAdsLeadLabel`, `googleAdsCallLabel` | мітки конверсій «Заявка» і «Дзвінок» | облік конверсій |
| `ga4Id` | `G-XXXXXXX` (необов’язково) | Google Analytics 4 |
| `googleSiteVerification` | код із Search Console | підтвердження сайту |

Форму можна підключити до Formspree, Web3Forms, Basin або власного обробника (POST, відповідь 2xx).
Повідомлення «Заявку прийнято» з’являється лише після реальної відправки.

## 2. Розміщення

Будь-який статичний хостинг з HTTPS. Найпростіше — **Cloudflare Pages** або **Netlify**:
папка публікації `site`, команда збірки `node tools/build.mjs` (або збирайте локально).
Файл `site/_headers` додає заголовки безпеки та кешування. `site/404.html` — сторінка помилки.

## 3. Чек-лист Google Ads (щоб оголошення показувались і акаунт не блокували)

Що вже зроблено на сайті:

- Справжні ціни в гривнях, наявність, умови доставки, оплати, гарантії та повернення на окремих сторінках.
- Політика конфіденційності, публічна оферта, контакти; згода в кожній формі.
- Жодних неперевірюваних тверджень («найнижча ціна в Україні», лічильники, фальшиві відгуки, таймери).
- Чітко сказано, що ми дилер, а не виробник EDON (політика Google щодо неправдивого представлення).
- Унікальні тексти (не скопійовані з інших магазинів — Google знижує якість дублікатів).
- Швидкість: LCP ≈ 0,15 с у тесті, нульовий зсув макета, сторінка ~440 КБ; адаптив 320–1440 px.
- `robots.txt` явно дозволяє `AdsBot-Google`; немає редиректів, клоакінгу, спливних вікон.
- Schema.org: Store, Product з Offer, доставкою й політикою повернення, BreadcrumbList.
- `merchant-feed.xml` для Google Merchant Center (з’явиться після заповнення `domain`).
- Конверсії: подія при успішній заявці та при натисканні на телефон (`assets/site.js`).

Що зробити вам:

1. Заповнити `data/site.json` (таблиця вище) і перезібрати сайт.
2. Підключити домен з HTTPS.
3. Пройти **верифікацію рекламодавця** в Google Ads (документи ФОП/ТОВ) — назва юрособи
   має збігатися з тією, що на сайті.
4. Додати сайт у Google Search Console та надіслати `sitemap.xml`.
5. У Merchant Center додати фід `https://ваш-домен/merchant-feed.xml`, вказати доставку 0 ₴ по Україні
   та політику повернення (посилання на `/harantiia-ta-povernennia/`).
6. Замінити стокові фото (hero, кран, щитова) на власні: двір/склад з генераторами, розвантаження,
   запуск на об’єкті. Список — у розділі нижче.
7. У тексті оголошень використовуйте ті самі факти, що на сайті: ціни, «доставка 0 ₴»,
   «запуск і навчання на місці», «гарантія 12 місяців».
